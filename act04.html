Mecanismos de defensa en red (Configuración Firewall)

📄 Descargar PDF Original

1. INTRODUCCIÓN CONTEXTUAL

La configuración de mecanismos de defensa perimetral es esencial para proteger una red interna (LAN) de amenazas externas. En esta práctica se implementa un firewall de filtrado de paquetes utilizando la cadena FORWARD de iptables. A diferencia de la cadena INPUT (que protege al propio servidor), FORWARD controla el tráfico que atraviesa el dispositivo, actuando como un verdadero guardián entre la red local e Internet.

2. DESARROLLO TÉCNICO

Se estableció una arquitectura de seguridad basada en el principio de "Denegar por defecto" (Default Deny). Esto significa que se bloquea todo el tráfico de paso y solo se habilitan explícitamente los servicios necesarios.

Servicios Habilitados:

    [cite_start]
  • DNS (Puerto 53): Resolución de nombres para la red local 192.1.2.0/24[cite: 251].
    • [cite_start]
  • SMTP (Puerto 25): Flujo de correo entrante y saliente para el servidor 192.1.2.10[cite: 253, 255].
    • [cite_start]
  • HTTP (Puerto 80): Acceso al servidor web 192.1.2.11 y navegación para usuarios locales[cite: 256, 257].

3. MATERIAL MULTIMEDIA

Implementación de Reglas de Filtrado (Script de Configuración):

# 1. POLÍTICA BASE: RESTRICTIVA (Muro de Fuego) iptables -P FORWARD DROP # 2. STATEFUL INSPECTION: Permitir respuestas legítimas iptables -A FORWARD -m state --state ESTABLISHED,RELATED -j ACCEPT # 3. REGLAS DE SERVICIOS (Ejemplos clave) # Permitir correo entrante al servidor interno iptables -A FORWARD -p tcp -d 192.1.2.10 --dport 25 -m state --state NEW -j ACCEPT # Permitir tráfico Web hacia el servidor público (DMZ) iptables -A FORWARD -p tcp -d 192.1.2.11 --dport 80 -m state --state NEW -j ACCEPT

[cite_start]Análisis: El uso de -m state --state ESTABLISHED,RELATED [cite: 250] es crítico; permite que el firewall reconozca automáticamente las respuestas a las peticiones que él mismo autorizó, reduciendo la complejidad de las reglas.

4. OPINIÓN O REFLEXIÓN TÉCNICA

[cite_start]La implementación de una política DROP por defecto en la cadena FORWARD es la medida de seguridad más robusta para un firewall perimetral. Si se usara ACCEPT por defecto, tendríamos que conocer y bloquear cada amenaza existente, lo cual es imposible. Al denegar todo y solo abrir lo necesario (DNS, SMTP, HTTP), reducimos drásticamente la superficie de ataque, garantizando que solo el tráfico de negocio legítimo pueda cruzar nuestra red.
